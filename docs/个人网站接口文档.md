# 个人网站接口文档

Nov 4, 2026 · @Lxjn Long

所有接口统一以 /api 开头，返回 JSON。用户端开发阶段由 Nuxt 的 server/api 提供样例数据，后端确定后整体代理过去，前端调用地址不变。

## 通用约定

所有接口以 `/api` 开头，不带版本号；请求和响应都是 UTF-8 JSON，时间统一用 ISO 8601 字符串（如 `2026-11-04T10:30:00+08:00`）。

| 项 | 约定 |
| --- | --- |
| 前缀 | 公开接口 `/api/*`；登录 `/api/auth/*`；管理接口 `/api/admin/*` |
| 命名 | 路径用小写加连字符（`friend-links`），字段用小驼峰（`publishedAt`） |
| 返回格式 | `{ code, message, data }`，`code = 0` 表示成功 |
| 分页 | 请求 `page`（从 1 开始）、`size`（默认 10，最大 50）；返回 `data = { list, total, page, size }` |
| 语言 | 请求头 `Accept-Language: zh-CN` 或 `en`；只影响 `message` 等系统文案，文章、项目等内容按原文返回 |
| 鉴权 | 公开接口无需登录；管理接口带 `Authorization: Bearer <Access Token>` 或 API Key |
| HTTP 状态码 | 业务错误也返回 200，靠 `code` 区分；仅 401（未登录）、403（无权限）、404（地址不存在）、429（限流）、500 使用对应状态码 |

成功响应示例：

```json
{ "code": 0, "message": "ok", "data": { } }
```

错误码：

| code | 含义 |
| --- | --- |
| 0 | 成功 |
| 40000 | 参数错误，`message` 说明哪个字段 |
| 40100 | 未登录或 Token 失效 |
| 40300 | 无权限 |
| 40400 | 资源不存在（如文章 slug 不存在） |
| 40900 | 数据冲突（如友链地址已申请过） |
| 42200 | 人机验证未通过 |
| 42900 | 请求过于频繁 |
| 50000 | 服务器内部错误 |

## 接口总览

用户端共 12 个公开接口，都不需要登录；其中 /api/chat 属于二期，一期不实现。

| 模块 | 方法 | 地址 | 说明 | 使用页面 |
| --- | --- | --- | --- | --- |
| 站点 | GET | `/api/site` | 站点名、背景、页足、开关等公开配置 | 全站布局 |
| 资料 | GET | `/api/profile` | 个人资料 + 可见的联系方式 | 首页、关于、博客侧栏 |
| 资料 | GET | `/api/skills` | 技术栈 | 首页、关于 |
| 资料 | GET | `/api/experiences` | 工作经历 | 关于 |
| 项目 | GET | `/api/projects` | 项目列表 | 首页、项目 |
| 文章 | GET | `/api/posts` | 文章列表（仅已发布） | 博客 |
| 文章 | GET | `/api/posts/:slug` | 文章详情 + 上下篇 | 文章详情 |
| 文章 | GET | `/api/categories` | 分类及文章数 | 博客侧栏 |
| 文章 | GET | `/api/tags` | 标签及文章数 | 博客侧栏 |
| 友链 | GET | `/api/friend-links` | 已通过的友链 | 页足 |
| 友链 | POST | `/api/friend-links/apply` | 提交友链申请 | 页足弹窗 |
| 访客问答 | POST | `/api/chat` | AI 问答，流式返回（二期） | 全站右下角 |

RSS 订阅地址 `/rss.xml` 是给阅读器访问的 XML 文件，不是数据接口，由 Nuxt 的服务端路由生成，不放在 `/api` 下。

## 站点与资料

### GET /api/site

全站布局在服务端渲染时请求一次，返回公开的站点配置，不含任何密钥。

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "name": "[你的名字]",
    "slogan": "[一句话签名]",
    "domain": "https://example.com",
    "background": { "mode": "glow", "image": null, "overlay": 0.7 },
    "fullPageScroll": true,
    "footer": {
      "copyright": "本站文章除特别说明外均采用 CC BY-NC-SA 4.0 协议",
      "icp": "[ICP 备案号]",
      "showAdminEntry": true
    },
    "friendLinkApply": { "enabled": true, "ready": true, "reviewDays": 3 },
    "captcha": { "provider": "turnstile", "siteKey": "0x4AAAA..." },
    "chatEnabled": false
  }
}
```

| 字段 | 说明 |
| --- | --- |
| background.mode | `plain` 纯色 / `glow` 光晕 / `image` 背景图 |
| background.overlay | 背景图上浅色蒙层的不透明度，0.6–0.8 |
| fullPageScroll | 首页是否整屏滚动；手机端始终退化为普通滚动 |
| captcha | 人机验证服务商和公开的 siteKey，前端据此加载 SDK |

### GET /api/profile

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "name": "[你的名字]",
    "title": "全栈开发者",
    "avatar": "https://example.com/avatar.png",
    "city": "[所在城市]",
    "years": 5,
    "homeIntro": "[两行以内的简介，用于首页第 1 屏]",
    "aboutMd": "[关于页的个人介绍，Markdown]",
    "contacts": [
      { "type": "github", "label": "GitHub", "value": "https://github.com/xxx" },
      { "type": "email", "label": "邮箱", "value": "you@example.com" },
      { "type": "rss", "label": "RSS", "value": "/rss.xml" }
    ]
  }
}
```

`contacts` 只返回设置为可见的项，已按后台排序。

### GET /api/skills

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| home | 0 / 1 | 否 | 1 = 只返回首页展示的前 8 个主力技术，平铺返回 |

不带 `home` 时按分组返回，用于关于页：

```json
{
  "code": 0,
  "message": "ok",
  "data": [
    {
      "group": "前端",
      "items": [
        { "name": "Vue 3", "mark": "V", "level": "main" },
        { "name": "Nuxt", "mark": "N", "level": "main" },
        { "name": "Svelte", "mark": "S", "level": "familiar" }
      ]
    }
  ]
}
```

`level`：`main` 主力（蓝色标签）/ `familiar` 了解（灰色标签）。`home=1` 时 `data` 为 `[{ name, mark, category }]`，`category` 是首页卡片下方的小字（如“前端”“构建”）。

### GET /api/experiences

```json
{
  "code": 0,
  "message": "ok",
  "data": [
    {
      "id": 1,
      "company": "[公司名称]",
      "role": "[职位]",
      "startMonth": "2023-07",
      "endMonth": null,
      "items": ["[负责的主要工作]", "[取得的成果]"],
      "tags": ["Vue 3", "TypeScript"]
    }
  ]
}
```

按时间倒序；`endMonth` 为 `null` 表示至今，前端显示为“至今 / Present”。

## 项目

### GET /api/projects

项目数量少，不分页，一次返回全部，按后台排序。

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| category | string | 否 | `web` / `tool` / `mobile` / `hw`，不传返回全部 |
| featured | 0 / 1 | 否 | 1 = 只返回首页精选（最多 3 个） |

```json
{
  "code": 0,
  "message": "ok",
  "data": [
    {
      "id": 1,
      "name": "[项目名称 1]",
      "description": "[一句话说明它做了什么、解决了什么问题]",
      "cover": "https://example.com/p1.webp",
      "icon": "window",
      "category": "web",
      "status": "maintaining",
      "techTags": ["Vue 3", "Naive UI"],
      "repoUrl": "https://github.com/xxx/p1",
      "demoUrl": "https://p1.example.com",
      "postSlug": "p1-retrospective",
      "featured": true
    }
  ]
}
```

| 字段 | 说明 |
| --- | --- |
| category | 筛选按钮文案由前端国际化：全部 / Web 应用 / 工具 / 移动端 / 硬件 |
| status | `doing` 进行中（warning）/ `maintaining` 维护中（success）/ `done` 已完成（默认），括号内为 n-tag 的 type |
| icon | 首页精选卡片左上角图标名，前端映射到图标组件 |
| cover / repoUrl / demoUrl / postSlug | 可为 `null`，为空时不显示对应封面或链接；`postSlug` 指向“项目复盘”文章 |

## 文章

### GET /api/posts

只返回已发布文章；置顶文章排最前，其余按发布时间倒序。列表不含正文。

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| q | string | 否 | 搜索标题、摘要、标签名 |
| category | string | 否 | 分类 slug |
| tag | string | 否 | 标签 slug |
| page | number | 否 | 默认 1 |
| size | number | 否 | 默认 10，最大 50 |

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "list": [
      {
        "id": 12,
        "slug": "nuxt-naive-ui-ssr",
        "title": "[文章标题]",
        "summary": "[文章摘要，列表中最多显示两行]",
        "cover": null,
        "category": { "name": "前端", "slug": "frontend" },
        "tags": [{ "name": "Nuxt", "slug": "nuxt" }],
        "isTop": false,
        "readMinutes": 8,
        "views": 326,
        "publishedAt": "2026-10-30T20:00:00+08:00"
      }
    ],
    "total": 42,
    "page": 1,
    "size": 10
  }
}
```

`readMinutes` 由后端按正文字数估算（中文约 400 字 / 分钟）。

### GET /api/posts/:slug

返回正文 Markdown 和上下篇；每次请求访问量 +1（后端可按 IP 在一段时间内去重）。slug 不存在或未发布时返回 `code = 40400`，前端显示 404 页。

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "id": 12,
    "slug": "nuxt-naive-ui-ssr",
    "title": "[文章标题]",
    "summary": "[文章摘要]",
    "cover": null,
    "content": "## 正文排版示例\n\n这是一段正文……",
    "category": { "name": "前端", "slug": "frontend" },
    "tags": [{ "name": "Nuxt", "slug": "nuxt" }],
    "readMinutes": 8,
    "views": 327,
    "publishedAt": "2026-10-30T20:00:00+08:00",
    "updatedAt": "2026-11-01T09:12:00+08:00",
    "prev": { "slug": "vite-config-notes", "title": "[上一篇文章标题]" },
    "next": null
  }
}
```

- `content` 是 Markdown 原文，由前端在服务端渲染时转成 HTML，并按 h2 / h3 生成目录。
- `prev` 是更早发布的一篇，`next` 是更晚的一篇；没有时为 `null`。

### GET /api/categories

按后台排序返回，`count` 只统计已发布文章；“全部”由前端自行拼在最前。

```json
{ "code": 0, "message": "ok", "data": [ { "name": "前端", "slug": "frontend", "count": 18 } ] }
```

### GET /api/tags

按文章数倒序返回，不返回文章数为 0 的标签。

```json
{ "code": 0, "message": "ok", "data": [ { "name": "Vue 3", "slug": "vue3", "count": 9 } ] }
```

## 友情链接

### GET /api/friend-links

只返回已通过的友链，按后台排序。

```json
{
  "code": 0,
  "message": "ok",
  "data": [
    { "id": 3, "name": "[友链名称 1]", "url": "https://friend.example.com", "avatar": "https://friend.example.com/logo.png", "description": "[一句话简介]" }
  ]
}
```

### POST /api/friend-links/apply

页足“申请友链”弹窗提交。`/api/site` 中 `friendLinkApply.enabled` 为 `false` 时前端不显示入口，后端也拒绝请求。

| 字段 | 类型 | 必填 | 校验 |
| --- | --- | --- | --- |
| name | string | 是 | 1–30 字 |
| url | string | 是 | http(s) 地址；同一地址已在待审核或已通过时返回 40900 |
| avatar | string | 否 | http(s) 地址 |
| description | string | 否 | ≤ 50 字 |
| email | string | 是 | 邮箱格式；不公开，用于通知审核结果 |
| backlinkUrl | string | 否 | 对方放置本站链接的页面 |
| captchaToken | string | 是 | 人机验证票据，后端校验，失败返回 42200 |

请求示例：

```json
{
  "name": "小王的博客",
  "url": "https://wang.example.com",
  "avatar": "https://wang.example.com/avatar.png",
  "description": "记录前端与生活",
  "email": "wang@example.com",
  "backlinkUrl": "https://wang.example.com/links",
  "captchaToken": "xxxx"
}
```

成功响应：

```json
{ "code": 0, "message": "ok", "data": { "id": 15, "status": "pending" } }
```

限流：同一 IP 每小时最多 3 次，超出返回 42900。弹窗里的“本站信息”直接用 `/api/site` 和 `/api/profile` 的数据，不单独设接口。

当前用户端支持 Cloudflare Turnstile。启用申请时，将数据库中的 `login.captchaProvider` 设为 `type=1`、`value=turnstile`，将 `login.captchaSiteKey` 设为 `type=1`、值为公开站点密钥，将 `footer.friendLinkApplyEnabled` 设为 `type=2`、`value=1`，并在服务端设置 `NUXT_TURNSTILE_SECRET`。部署在反向代理后时，由代理覆盖 `X-Forwarded-For` 为实际客户端地址，并设置 `NUXT_TRUST_PROXY=true`。设置稳定的 `NUXT_IP_HASH_SALT` 可保持地址限流记录有效。

## 数据类型

以下类型放在用户端 `types/api.ts`，样例数据和页面共用，保证换成真实后端后字段一致。

```ts
/** 统一响应结构 */
export interface ApiResult<T> {
  code: number
  message: string
  data: T
}

/** 分页结果 */
export interface PageResult<T> {
  list: T[]
  total: number
  page: number
  size: number
}

export type BackgroundMode = 'plain' | 'glow' | 'image'
export type ProjectCategory = 'web' | 'tool' | 'mobile' | 'hw'
export type ProjectStatus = 'doing' | 'maintaining' | 'done'
export type SkillLevel = 'main' | 'familiar'
export type ContactType = 'github' | 'email' | 'rss' | 'custom'

/** GET /api/site */
export interface SiteConfig {
  name: string
  slogan: string
  domain: string
  background: { mode: BackgroundMode; image: string | null; overlay: number }
  fullPageScroll: boolean
  footer: { copyright: string; icp: string; showAdminEntry: boolean }
  friendLinkApply: { enabled: boolean; ready: boolean; reviewDays: number }
  captcha: { provider: 'turnstile' | 'geetest' | 'tencent'; siteKey: string }
  chatEnabled: boolean
}

export interface Contact {
  type: ContactType
  label: string
  value: string
}

/** GET /api/profile */
export interface Profile {
  name: string
  title: string
  avatar: string
  city: string
  years: number
  homeIntro: string
  aboutMd: string
  contacts: Contact[]
}

export interface Skill {
  name: string
  mark: string
  level: SkillLevel
}

/** GET /api/skills */
export interface SkillGroup {
  group: string
  items: Skill[]
}

/** GET /api/skills?home=1 */
export interface HomeSkill {
  name: string
  mark: string
  category: string
}

/** GET /api/experiences */
export interface Experience {
  id: number
  company: string
  role: string
  startMonth: string
  endMonth: string | null
  items: string[]
  tags: string[]
}

/** GET /api/projects */
export interface Project {
  id: number
  name: string
  description: string
  cover: string | null
  icon: string
  category: ProjectCategory
  status: ProjectStatus
  techTags: string[]
  repoUrl: string | null
  demoUrl: string | null
  postSlug: string | null
  featured: boolean
}

export interface Taxonomy {
  name: string
  slug: string
}

/** GET /api/categories、/api/tags */
export interface TaxonomyCount extends Taxonomy {
  count: number
}

/** GET /api/posts 列表项 */
export interface PostSummary {
  id: number
  slug: string
  title: string
  summary: string
  cover: string | null
  category: Taxonomy
  tags: Taxonomy[]
  isTop: boolean
  readMinutes: number
  views: number
  publishedAt: string
}

/** GET /api/posts/:slug */
export interface PostDetail extends Omit<PostSummary, 'isTop'> {
  content: string
  updatedAt: string
  prev: { slug: string; title: string } | null
  next: { slug: string; title: string } | null
}

/** GET /api/friend-links */
export interface FriendLink {
  id: number
  name: string
  url: string
  avatar: string | null
  description: string | null
}

/** POST /api/friend-links/apply 请求体 */
export interface FriendLinkApply {
  name: string
  url: string
  avatar?: string
  description?: string
  email: string
  backlinkUrl?: string
  captchaToken: string
}
```

## 管理接口概览

管理端接口先定地址和分组，参数与返回在开发管理端时再补全。登录相关在 `/api/auth`，其余全部在 `/api/admin` 下，都需要登录。

| 模块 | 接口 |
| --- | --- |
| 认证 | POST `/api/auth/login`（密码）、POST `/api/auth/code/send`、POST `/api/auth/code/login`、GET `/api/auth/qr`、GET `/api/auth/qr/:id/status`、GET `/api/auth/oauth/:provider` + 回调、POST `/api/auth/refresh`、POST `/api/auth/logout` |
| 仪表盘 | GET `/api/admin/dashboard?range=7d` |
| 文章 | GET/POST `/api/admin/posts`、GET/PUT/DELETE `/api/admin/posts/:id`、POST `/api/admin/posts/batch-delete`、PUT `/api/admin/posts/:id/draft` |
| 分类标签 | `/api/admin/categories`、`/api/admin/tags` CRUD，PUT `/api/admin/categories/sort` |
| 项目 | `/api/admin/projects` CRUD，PUT `/api/admin/projects/sort`、PATCH `/api/admin/projects/:id/featured` |
| 资料 | GET/PUT `/api/admin/profile`、PUT `/api/admin/skills`、PUT `/api/admin/experiences`、PUT `/api/admin/contacts` |
| 文件 | GET/POST `/api/admin/files`、DELETE `/api/admin/files/:id`、GET `/api/admin/files/:id/refs` |
| 友链 | `/api/admin/friend-links` CRUD、PATCH `/api/admin/friend-links/:id/status` |
| 设置 | GET/PUT `/api/admin/settings/:group`（basic / look / footer / login / api / ai） |
| 账号 | PUT `/api/admin/account/password`、绑定 / 解绑手机、邮箱、第三方、GET `/api/admin/account/login-logs` |
| 系统 | GET/PUT `/api/admin/system/database`、POST `/api/admin/system/database/test`、`/api/admin/system/backups`、`/api/admin/storage-repos` CRUD + test + default |
| 开发者 | `/api/admin/api-keys` CRUD |
| AI | `/api/admin/ai-providers` CRUD + test + default、POST `/api/admin/ai/assist`（流式） |

用户端的 Nuxt 样例接口不实现 `/api/auth` 和 `/api/admin`。

## 样例数据与切换后端

后端确定前，每个公开接口在 Nuxt 的 `server/api` 下对应一个文件，返回样例数据；样例数据本身放在 `server/mock/`，并使用上面的类型。

| 接口 | 文件 |
| --- | --- |
| GET /api/site | `server/api/site.get.ts` |
| GET /api/profile | `server/api/profile.get.ts` |
| GET /api/skills | `server/api/skills.get.ts` |
| GET /api/experiences | `server/api/experiences.get.ts` |
| GET /api/projects | `server/api/projects.get.ts` |
| GET /api/posts | `server/api/posts/index.get.ts` |
| GET /api/posts/:slug | `server/api/posts/[slug].get.ts` |
| GET /api/categories | `server/api/categories.get.ts` |
| GET /api/tags | `server/api/tags.get.ts` |
| GET /api/friend-links | `server/api/friend-links/index.get.ts` |
| POST /api/friend-links/apply | `server/api/friend-links/apply.post.ts` |

样例接口要实现真实的筛选、搜索和分页，友链申请也要做必填和格式校验，这样页面交互在没有后端时也能完整联调。

后端就绪后：

1. 删掉 `server/api` 和 `server/mock` 中对应的文件。
2. 在 `nuxt.config.ts` 里把 `/api/**` 代理到后端地址，地址从环境变量读取：

```ts
export default defineNuxtConfig({
  routeRules: {
    // 把所有 /api 请求转发给后端，页面里的 useFetch('/api/...') 无需修改
    '/api/**': { proxy: `${process.env.API_BASE}/api/**` }
  }
})
```

3. 也可以不走 Nuxt，由 Nginx 直接把 `/api/` 转发到后端；两种方式前端代码都不用改。

待定：文章、项目等内容是否需要英文版。目前约定只有界面文案做中英文，内容按原文返回；若要双语内容，需要调整数据模型和接口。
